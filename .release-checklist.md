# Plan Do Launch Private Release Checklist

Internal checklist for local QA and deployment verification.

## 1) CTA Consistency

- Search for old CTA copy:
  - `Run the Capacity Diagnostic`
  - `Run the Assessment`
- Confirm target copy is used where intended:
  - `Measure your onboarding capacity`
- In assessment flow, allow in-flow CTA labels like `Start` or `Begin Assessment`.

Quick checks:

- `rg "Run the Capacity Diagnostic|Run the Assessment" . -g "*.html"`
- `rg "Measure your onboarding capacity|btn-assessment-cta|cta-sub" . -g "*.html"`

## 2) CTA Destination Consistency

- Ensure one canonical CTA destination is used across pages:
  - `https://plandolaunch.com/assessment/`
- Remove mixed destination variants unless intentionally used.

Quick checks:

- `rg "assessment\\.plandolaunch\\.com|href=\"/assessment\"" . -g "*.html"`
- `rg "https://plandolaunch.com/assessment/" . -g "*.html"`

## 3) Assessment Nav CTA Suppression

- On assessment pages, nav CTA should be hidden.
- On marketing pages, nav CTA should be visible.

Verify pages:

- `/assessment/index.html`
- `/assessment/section-one.html`
- `/index.html`

## 4) Placeholder/Empty Link Cleanup

- Remove `href="#"` placeholders and empty nav links.

Quick check:

- `rg "href=\"#\"" . -g "*.html"`

## 5) Metadata Coverage (Core Pages)

Each core page should include:

- `title`
- `meta description`
- `canonical`
- OG tags (`og:title`, `og:description`, `og:url`, `og:image`)
- Twitter tags (`twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`)

Core pages:

- `/index.html`
- `/about.html`
- `/contact.html`
- `/blog/index.html`
- `/404.html`

## 6) Schema Coverage

- Home: `ProfessionalService`
- About: `AboutPage`
- Contact: `ContactPage`
- Blog index: `Blog`
- Blog articles: `Article`

Quick check:

- `rg "application/ld\\+json" . -g "*.html"`

## 7) Blog Article Metadata Consistency

For every blog post:

- Canonical is present and points to final URL.
- OG image is absolute URL.
- Twitter image matches OG image.
- `Article` schema includes headline, author, publisher, url, image, description.

Quick checks:

- `rg "rel=\"canonical\"" blog -g "*.html"`
- `rg "twitter:image|og:image|application/ld\\+json" blog -g "*.html"`

## 8) External Link Hardening

- For links with `target="_blank"`, include:
  - `rel="noopener noreferrer"`

Quick check:

- `rg "target=\"_blank\"" . -g "*.html"`

## 9) Favicon Consistency

- Standardize favicon reference across all pages.
- Prefer one file and one path pattern.

Quick check:

- `rg "favicon|pdl_favicon_64.png" . -g "*.html"`

## 10) Deploy + Live Verification

After publish:

1. Hard refresh browser (`Cmd+Shift+R`).
2. Validate these URLs:
   - `/`
   - `/contact.html`
   - `/assessment/index.html`
   - one blog post URL
   - `/404.html`
3. Confirm live copy/links match local export.
4. Purge CDN cache if stale content appears.

## Optional One-Pass QA Commands

Run from repo root:

- `rg "Run the Capacity Diagnostic|Run the Assessment|href=\"#\"|assessment\\.plandolaunch\\.com|href=\"/assessment\"" . -g "*.html"`
- `rg "rel=\"canonical\"|application/ld\\+json|twitter:title|twitter:description|twitter:image|og:type|og:url|og:image" . -g "*.html"`
